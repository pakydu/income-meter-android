# 收入显示器 - 需求与设计文档

## 1. 项目概述

**项目名称**: 收入显示器
**项目类型**: Android 原生应用
**版本**: v1.1
**作者**: paky.pc.du@qq.com

### 1.1 项目简介
一个帮助你实时查看收入的小工具，通过计时方式展示你的工作收入，按照月薪 ÷ 22工作日 ÷ 8小时 ÷ 3600秒 的公式计算每秒收入。

### 1.2 核心功能
- 实时计时收入计算与显示
- 月薪可配置（默认 10,000 元）
- 本月累计收入统计
- 今日已赚收入统计

## 3. 功能需求

### 3.1 主页面功能

#### 3.1.1 计时控制区
- 开始/暂停/继续计时按钮
- 计时状态指示（未开始/计时中/已暂停）
- 状态指示点动画效果

#### 3.1.2 今日已赚卡片
- **更新频率**: 快速更新（每帧刷新，约 60fps）
- 显示内容:
  - 今日已赚金额（6位小数）
  - 工作进度条（9:00-18:00 工作制）

#### 3.1.3 本月累计卡片（集成在今日已赚卡片内）
- **更新频率**: 每 5 元更新一次（节流优化）
- 显示内容:
  - 本月累计收入（2位小数）
  - 本月进度（已过天数/22个工作日）

#### 3.1.4 实时收入速率区
以 2x2 网格布局展示：
| 项目 | 说明 |
|------|------|
| 每秒收入 | 6位小数 |
| 每分钟收入 | 4位小数 |
| 每小时收入 | 2位小数 |
| 日薪 | 月薪 ÷ 22 工作日 |

#### 3.1.5 底部月薪信息区
- 显示当前配置的月薪
- 月薪通过设置页面修改

#### 3.1.6 底部说明
- 计算公式显示：月薪 ÷ 22工作日 ÷ 8小时 ÷ 3600秒

## 5. 数据规格

### 5.1 收入计算公式
```
每秒收入 = 月薪 ÷ 22 ÷ 8 ÷ 3600
每分钟收入 = 月薪 ÷ 22 ÷ 8 ÷ 60
每小时收入 = 月薪 ÷ 22 ÷ 8
日薪 = 月薪 ÷ 22
```

### 5.2 时间计算规则
- **工作日**: 每月 22 个工作日
- **每日工作时长**: 8 小时（9:00 - 18:00）
- **本月累计计算**: 从月初到今日已完成的工作日收入 + 今日已工作时间收入

### 5.3 SharedPreferences 存储
| Key | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| monthly_salary | Float | 10000.0 | 月薪设置 |

## 6. 动画规格

### 6.1 数字动画
- **类型**: ValueAnimator
- **时长**: 300ms
- **插值器**: DecelerateInterpolator
- **触发条件**: 月度累计每变化 5 元时触发

### 6.2 状态点脉冲动画
- **类型**: Alpha Animation
- **时长**: 600ms
- **循环**: 无限循环
- **透明度**: 1.0 → 0.2 → 1.0

### 6.3 UI 刷新频率
- **计时状态**: 约 60fps (16ms 间隔)
- **月度累计**: 每 5 元更新一次
